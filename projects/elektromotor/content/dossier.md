# Досье: мотор постоянного тока класса Mabuchi 130

Важно: страницы openstax.org и mantech.co.za в этой сессии недоступны (хост не открывается), поэтому первоисточники прочитаны только в выдержках поиска. Чертёж и текст учебника нужно сверить вручную или разрешить эти домены.

## Что показываем
Один коллекторный мотор постоянного тока с магнитами (класс FF/RF-130): снаружи, в разрезе, затем схема одной рамки. Корпус ~20.4 x 15.4 мм в сечении, длина ~25 мм, вал 2 мм, щётки в FF-130SH из драгметалла, масса ~24 г (D5, D6). Размеры только для пропорций, на кадре без чисел.

## Проверка S1-S9
- S1 сила на провод с током: подтверждено (OpenStax UP2 §11.5, лекция MIT 8.02x).
- S2 перпендикулярна току и полю: подтверждено (F = I L x B).
- S3 больше ток или поле, больше сила: подтверждено.
- S4 силы на сторонах рамки противоположны, остаётся момент: подтверждено (суммарная сила 0).
- S5 момент ноль при плоскости рамки перпендикулярно полю: подтверждено (tau = IAB sin theta).
- S6 без смены тока момент назад: упрощено (с инерцией рамка может проскочить; «качнётся назад или остановится» верно).
- S7 коллектор меняет ток каждые пол-оборота: упрощено (верно для двухпластинчатого).
- S8 несколько обмоток, ровнее: подтверждено по сути (JoVE: нужно не меньше трёх площадок), прямой цитаты «ровнее» нет.
- S9 электрическая энергия в механическую: не подтверждено первоисточником в этой сессии (общее положение).

## Где популярное объяснение расходится с источниками
1. Популярно: «рамка с двумя пластинами коллектора». У реального мотора 130 якорь обычно с тремя катушками и тремя сегментами (по общим данным, источником не проверено), потому что у двух пластин есть мёртвая зона. Схему называем «простейшим мотором».
2. Популярно: «магнит притягивает рамку». По источникам: сила Ампера на проводник с током, перпендикулярная полю.
3. Популярно: «без коллектора мотор остановится». Точнее: момент меняет знак, рамка качается.
4. Длина вала: в даташите 38.0 и 38.75 REF, смысл неясен (вал или общая длина).
