# Раскадровка: Как работает Claude

Черновик для СТОП 1 (19.11.2026). Голос не генерировался. Структура A (concept.md). Метафор нет (§20): интерфейс — буквально, токены и варианты — схема, «внутри модели» — схема по рисунку S1 (граф связей понятий), без «мозга» и механизмов.

Сквозные решения: коралловый — **выбранный токен** (тот кусочек, который модель выдаёт / выбрала заранее); один смысл на весь ролик. Вероятности — неравные полоски **без чисел** (не измерения, analysis.md §8.4). Английские слова примера S1 (grab it, rabbit, habit, green) показаны как есть, с русской подписью; русскую рифму не придумываем.
