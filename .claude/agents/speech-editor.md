- **`speech-editor`.** Ищет канцелярит, фразы длиннее 12 слов, трудные стечения звуков, слова с неоднозначным ударением, аббревиатуры, латиницу и имена, которые голос может прочитать неверно. Для каждого места предлагает замену слова; если замена невозможна, предлагает способ записи по руководству модели голоса. Проверяет букву ё и расстановку аудиотегов.

### Требования к сценарию

- **Крючок.** Первые 2 секунды — парадокс, вопрос или неожиданное число из источника. Не приветствие и не «в этом видео».
- **Фраза.** Одна фраза — одна мысль, 6–12 слов. Разговорный язык, без канцелярита.
- **Термины.** Термин вводится один раз и сразу объясняется простыми словами или сравнением из жизни зрителя.
- **Связность.** Каждая сцена отвечает на вопрос, который оставила предыдущая.
- **Числа.** Не больше одного числа на сцену. Диктор произносит округлённое, точное стоит в кадре.
- **Проверка картинкой.** К каждой фразе задай вопрос: что в этот момент на экране? Если показать нечего, перепиши фразу.
- **Структура.** Сцена длится 5–12 секунд, на каждые 60 секунд приходится 5–9 сцен: крючок, вопрос или проблема, объяснение по шагам, вывод. Призыв есть, только если в брифе задан cta; он встроен в последний тезис, а не идёт отдельной сценой.
- **Финал.** Вывод одной фразой возвращает к крючку. После последнего слова ролик длится не дольше 0,8 с, без прощаний и затухания. Последний кадр по композиции близок к первому, чтобы ролик зацикливался, и продолжает двигаться в состоянии покоя.

## 8. Голос, тайминги, субтитры, звук

Текст субтитров берётся из сценария, время — из Whisper, а графика привязана к словам диктора через именованные якоря.

### Сценарий в двух версиях

В `content/script.json` каждая сцена — список параллельных фрагментов по 2–6 слов. Фрагмент равен одной странице субтитров и не рвёт предлог от слова.

- `display` — текст для экрана: чистый, без тегов, с правильной орфографией.
- `tts` — текст для озвучки: те же слова плюс аудиотеги в квадратных скобках и пунктуация для пауз. Числа на `eleven_v4` остаются в обычной письменной форме.
- `beats` — якорные слова сцены с именами, например `{"id": "ledger", "word": "книга"}`.

### ElevenLabs

- Голос генерируется только через подключённый MCP-сервер ElevenLabs: модель `eleven_v4`, голос из брифа. Прямые вызовы API и другие модели — только с согласия пользователя.
- Перед первой генерацией прочитай описания инструментов сервера и руководство по модели. Идентификатор голоса бери из брифа или из списка голосов сервера, не по памяти.
- Одна сцена — один файл `public/audio/vo/<scene-id>.mp3`, один дубль: если инструмент по умолчанию делает несколько, задай один. Порядок получения файла: запусти генерацию с числом дублей 1, дождись завершения по статусу запуска, запроси результат генерации и скачай файл по выданной ссылке в проект; проверь его через ffprobe. Первую сцену сгенерируй отдельно и убедись, что файл получен, и только потом запускай остальные. Если получить файл нельзя, остановись и предложи пользователю прямой вызов API ElevenLabs с ключом в переменной окружения ELEVENLABS_API_KEY. Полученный файл сразу закоммить и отправь в репозиторий: он оплачен кредитами.
- Каждая генерация тратит кредиты. Не повторяй вызов «на всякий случай»; стоимость всего ролика оцени без расхода кредитов, режимом оценки инструмента генерации, и назови пользователю на СТОП 2.
- Кэш: `scripts/vo-cache.mjs` хранит хеш текста, голоса и модели каждой сцены. Сцена без изменений не перегенерируется.
- **Enhance.** При `voice_enhance: where_needed` расставь аудиотеги сам: это то же, что кнопка Enhance. Тег стоит перед словами, которые окрашивает, и действует до следующего тега.
- Теги описывают подачу, а не действие: `[excited]`, `[curious]`, `[warmly]`, `[softly]`, `[dramatically]`, `[short pause]`, `[pause]`. Пиши их по-английски, простыми словами, без дефисов.
- Мера: 1–3 тега на сцену и только там, где меняется подача: крючок, поворот мысли, вывод. Ровное объяснение идёт без тегов.
- Звуки вроде `[laughs]` и `[sighs]` в дикторском тексте не используй без запроса: они ломают выравнивание по словам.
- Ударение на слове выделяй ЗАГЛАВНЫМИ, редко. Паузы — запятая, тире, многоточие, `[pause]`.
- У `eleven_v4` нет параметра скорости. Темп задаётся тегом `[slowly]`, паузами и длиной текста.
- Проверка: распознай файл Whisper и сравни с `tts` без тегов. При оговорке, неверном ударении или пропущенном слове перегенерируй только эту сцену, изменив формулировку или тег. После 3 неудач сообщи пользователю.

### Whisper

- Скрипт `scripts/transcribe.mjs` использует `installWhisperCpp()`, `downloadWhisperModel()`, `transcribe()` и `toCaptions()` из `@remotion/install-whisper-cpp`.
- Вход — WAV 16 кГц, 16 бит, моно: `ffmpeg -i in.mp3 -ar 16000 -ac 1 -c:a pcm_s16le out.wav -y`.
- Параметры: `model: 'large-v3'`, `language` из брифа, `tokenLevelTimestamps: true`, `splitOnWord: true`. Модели с суффиксом `.en` для русского не подходят.
- Whisper отдаёт токены, а не слова. Склей токен без ведущего пробела с предыдущим и проверь, что кириллица не повреждена.

### Выравнивание

- Скрипт `scripts/align.mjs` сопоставляет слова Whisper со словами `tts` по порядку. Перед сравнением из `tts` удаляются теги в квадратных скобках, слова приводятся к нижнему регистру, без пунктуации, ё заменяется на е.
- Числа перед сравнением разворачиваются в слова с обеих сторон.
- Каждому слову сценария назначается `startMs` и `endMs`. Нераспознанное слово получает время между соседями.
- Если в `display` и `tts` разное число слов, время фрагмента делится между словами `display` пропорционально длине.
- Порог: если в сцене не выровнено больше 10 % слов, перегенерируй голос сцены. Долю выровненных слов укажи в отчёте.

### Единый таймлайн

- `scripts/build-timeline.mjs` собирает `src/data/timeline.json`. Перевод времени в кадры делает одна функция: `Math.round(ms / 1000 * fps)`.
- Длительность сцены = длительность её аудио + поле до голоса 0,25 с (15 кадров) + поле после голоса 0,35 с (21 кадр). На стыке с переходом оба поля не короче длины перехода: build-timeline.mjs увеличивает поле после голоса у сцены перед переходом и поле до голоса у сцены после него и сдвигает voiceStartFrame. Иначе переход наложится на речь.
- Поле после голоса увеличивается, когда этого требует движение: трансформация-герой заканчивается не позже чем за 0,3 с до конца сцены; у сцены перед главным выводом оно длиннее перехода на 0,3–0,5 с: это пауза ожидания до начала перехода.
- После последнего слова ролика поле не длиннее 0,8 с. Поэтому главный якорь последней сцены стоит не позже чем за 1,5 с до конца её речи: трансформация-герой заканчивается вместе с голосом.
- Кадр 0 первой сцены — обложка. Голос и субтитры начинаются с 15-го кадра.
- Якоря хранятся как кадр от начала сцены. Сцена обращается к якорю по имени, а не по номеру кадра, поэтому перегенерация голоса сама пересинхронизирует графику.
- Трансформация-герой стартует за 5 кадров до своего якоря. Кадры событий `sfx` внутри сцены считаются от её начала.
- Переходы `<TransitionSeries>` накладываются на поля сцен, а не на речь. Они описаны в массиве `transitions` верхнего уровня вместе со своим звуком; их длина вычитается из общей длительности в `calculateMetadata`.

### Субтитры

- Слой `Captions` лежит поверх сцен в зоне субтитров. Страница — один фрагмент: 1–2 строки, до 24 знаков в строке.
- Субтитры спокойнее графики: размер 52–60 px, тёмная полупрозрачная подложка, без ярких плашек.
- Активное слово выделяется цветом самого текста, а не заливкой фона: ширина слова не меняется, строка не прыгает.
- Страница появляется за 6–9 кадров.
- На время трансформации-героя субтитры приглушаются до 60 % непрозрачности, чтобы взгляд оставался на графике.
- Когда на экране стоит ключевой тезис, совпадающий с речью, субтитры этой фразы скрыты.
- При `captions: off` слой не рендерится, но тайминги всё равно строятся: на них держатся якоря.

### Звук

- **Музыка запрещена.** В ролике нет ни фоновой музыки, ни музыкальных акцентов, ни сгенерированных треков. Звук состоит из голоса и звуковых эффектов.
- **Голос** — `<Audio>` внутри `<Sequence>` своей сцены.
- **Звуковые эффекты обязательны.** Ролик без них считается незаконченным.
- **Источник** — только бесплатный пакет `@remotion/sfx`: `npx remotion add @remotion/sfx`, нужна версия Remotion не ниже 4.0.429. Другие источники и генерация эффектов — только по согласованию.
- **Использование:** `import {whoosh} from '@remotion/sfx'` и `<Audio src={whoosh} volume={0.25} />` внутри `<Sequence>` на кадре события. Актуальный список эффектов возьми из документации пакета через `/remotion-docs`, не по памяти.
- **Карта звука.** В раскадровке и в `timeline.json` (массив `sfx` сцены) эффект назначен на каждый переход между сценами, каждую трансформацию-героя и появление числа-героя. Дополнительно — на маркеры эмоций и главные якоря. Карту составляет субагент sound-designer в файле content/sound-map.md; в таймлайн её переносит build-timeline.mjs.
- **Плотность.** В среднем один эффект каждые 2–4 секунды; не больше двух эффектов в секунду.
- **Подбор.** Характер звука соответствует движению: быстрый пролёт, щелчок появления, мягкий удар посадки. Один тип движения звучит одинаково весь ролик.
- **Баланс.** Громкость эффектов 0,15–0,3. Эффект не заглушает слово диктора: при наложении на речь бери нижнюю границу.
- **Лицензии.** У каждого эффекта своя лицензия. Список использованных эффектов запиши в отчёт.
- Весь микс собирается в Remotion. В FFmpeg выполняется только нормализация громкости.

* **Если нужного звука нет.** Возьми ближайший из пакета и измени его характер скоростью воспроизведения и громкостью. Сторонние источники не подключай.
* **Сеть.** Пакет отдаёт адреса файлов на remotion.media, поэтому при рендере нужен интернет. Если файл не загрузился, рендер останавливается, а не продолжается без звука.
* **Тишина как приём.** Перед главным выводом 0,3–0,5 с без эффектов, затем самый заметный звук ролика.
