# Словарь символов эмоций (колесо Плутчика) — решения пользователя

Регламент v3.0, раздел 6: 8 базовых эмоций в трёх степенях силы (сила — размером символа) и 8 сочетаний; у каждого сочетания свой символ (решение 20.11.2026). Символ отвечает за причину: появляется на событии и уходит, когда причина снята. Строится в `src/lib/symbols`, строка в `catalog.json` — после выбора здесь.

## Базовые эмоции (слабая → базовая → сильная)
| Эмоция | Символ | Статус |
| --- | --- | --- |
| Радость (умиротворение → радость → восторг) | цветок (бутон → цветок → цветок с искрами) | есть, `bloom` |
| Доверие (принятие → доверие → восхищение) | мостик: доска перекидывается к другому и ложится на опору | выбран, строится |
| Страх (опасение → страх → ужас) | сжимающиеся стены вокруг человека, его тень растёт | выбран, строится |
| Удивление (рассеянность → удивление → изумление) | искры | есть, `sparks` |
| Грусть (задумчивость → грусть → горе) | грузики на плечах, фигура оседает | выбран, строится |
| Отвращение (скука → отвращение → ненависть) | отталкивающий магнит: предмет отталкивается, человек отклоняется | выбран, строится |
| Гнев (раздражение → гнев → ярость) | туча с молниями | есть, `storm` |
| Ожидание (интерес → ожидание → настороженность) | песочные часы, песок сыплется | выбран, строится |
