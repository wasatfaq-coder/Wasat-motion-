# Project instructions

This repository holds one motion-explainer video project driven by `MASTER_PROMPT.md`.

- At the start of every session, read `content/progress.md` if it exists and continue from the step recorded there. Do not restart finished stages and do not re-ask decisions already recorded.
- If `content/progress.md` does not exist, wait for the user to give the topic and source, then follow `MASTER_PROMPT.md` from stage 1.
- `MASTER_PROMPT.md` is the single source of rules. Do not change it unless the user asks.
- The user works from a phone: answer in Russian, keep messages short, send images and videos as files.
