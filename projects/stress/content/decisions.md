# Решения: Как стресс влияет на тело

| Дата | Решение | Кто |
| --- | --- | --- |
| 2026-11-25 | Формат `why`, не `how`: тема не про устройство. `how` вскрывает прибор, здесь механизм и символы. | пилот по запросу |
| 2026-11-25 | `sensitive: health`. Источник на экране в каждой главе, где звучит физиология. | регламент §13 |
| 2026-11-25 | Коралл значит «ответ тела» на весь ролик. Молнии тучи не коралловые: гнев не смысл темы. | словарь символов |
| 2026-11-25 | Карточка «эстафета оси» в статусе `proposed`: пилот её показывает, потому что так поставлен запрос. Утверждение пользователя на СТОП 1 ещё впереди. | регламент §6 |
| 2026-11-25 | Голоса нет: пилот без звука. Тайминг подписей приблизительный. | запрос пилота |
