# Project instructions

This repository produces vertical motion-explainer videos (YouTube Shorts) with Remotion. Rules: `MASTER_PROMPT_FINAL.md` (v2.7, the single source of rules; do not change it unless the user asks; changes go to `docs/CHANGELOG.md`).

## Topics: one folder per topic
- Finished / current topic «Почему нам кажется, что время течёт быстро» lives in the root layout (`content/`, `public/audio/`, `src/scenes/`). Its state: `content/progress.md`, `content/decisions.md`.
- **A new topic** (the user writes «Новая тема: …», «Выполни MASTER_PROMPT_FINAL.md. Тема: …» or similar) never continues the root `content/progress.md`. Create it with `node scripts/new-topic.mjs <slug> "<Тема>"`, which makes:
  - `projects/<slug>/content/` — brief, sources, analysis, script, storyboard, sound map, reviews, `progress.md`, `decisions.md`;
  - `public/<slug>/` — voice files, sfx copies, fonts if new (Remotion serves static files only from `public/`);
  - `src/projects/<slug>/` — scenes, Main and Cover for this topic, registered in `src/Root.tsx` under composition ids `<Slug>Main` and `<Slug>Cover`;
  - `scripts/` and shared code (`src/lib`, `src/theme`, `src/components` incl. `Episode`, `src/illustrations`) are reused; extend them, do not copy them. Scripts take `--content`, `--timeline`, `--comp` flags for a topic (MASTER_PROMPT_FINAL §21).
- **Continuing** a topic: read that topic's `progress.md` and `decisions.md` first and continue from the recorded step; do not re-ask recorded decisions.
- Each topic gets its own working branch and PR.

## Always
- **Before any work in an area, read its file — these rules bind exactly as if written here:** `docs/claude/style.md` (house style §22/§24, hero objects, covers, metaphors §20, handedness, parts files, coral), `docs/claude/motion.md` (pace, `*.motion.ts`, motion-check, §25), `docs/claude/qa.md` (audit, pregate, batch gate, contact sheets, sfx, master, root-cause process). Rules by section: `docs/rules/INDEX.md` → `docs/rules/NN.md` (generated by `node scripts/rules-split.mjs` from the master; CI checks sync; never edit by hand).
- Subagents may not be able to write files or open some sites: they return the full report as text, the main session saves it.
- **Context hand-over**: keep the current step, open findings and next actions in `docs/progress/<work>.md` (committed with the work). At 40% context use (read the session's context counter, never estimate: the window can be 1M tokens, so 40% is 400k), save that file, open a PR and merge it on green CI. The user works in ONE session: never start a new session (`create_session`) for a hand-over; the next session (or this one after compaction) continues from `docs/progress/<work>.md`.
- **Models (token economy)**: each agent in `.claude/agents/*.md` sets `model:` (haiku: first-viewer; opus: object-architect, shorts-quality-gate; sonnet: the rest); a new agent must set one too. A session created to continue routine work (build, fixes, checks between stops) uses `model: "claude-sonnet-5-5"` in `create_session`; STOP 1–3 gates, new-topic planning and hero-object geometry stay on Opus. Read rules by section (`docs/rules/INDEX.md`), not the whole `MASTER_PROMPT_FINAL.md`. Contact sheets for agents at scale 1×.
- **Root cause every time** (`docs/root-causes.md`): no defect is closed by a fix in one topic alone; fix shared code + add a guard (details: `docs/claude/qa.md`).
- Before showing frames, covers or video to the user, run the `shorts-quality-gate` agent (§19) and fix every defect it finds; facts go through `fact-checker`. After a PASS, stamp the exact files: `node scripts/gate-stamp.mjs --gate "<verdict>" <files>`; the PreToolUse hook `.claude/hooks/require-gate.mjs` blocks sending an unstamped image or video.
- Never merge a PR that adds or changes a video (a render, a demo or a master) until the session merging it has watched the new video itself (contact sheets and `node scripts/review-video.mjs`); green CI alone is not enough. A PR without a video is merged on green CI.
- Do not reuse illustrations or locations from another topic without the user's consent (§4); shared kits (room, city, board) are building blocks, the scenes are designed anew.
- Code map: for questions about how the code is wired or what a change in shared code (`src/lib`, `src/components`, `src/theme`) affects, use the `graph-pilot` skill (Graphify, installed by the SessionStart hook; `graphify update .` builds the graph in seconds, only code-only commands, never `graphify install`).
- The user works from a phone: answer in Russian, keep messages short, send images and videos as files.
