# Разбор трёх видео-референсов (20.11.2026)

Три вертикальных ролика 720×1280, 30 fps, с дикторским голосом (англ.). Разбор по кадрам каждые 2 с; речь не распознавалась (в среде нет whisper), звук оценён только по уровню (средний −15…−17 dB, пики до 0 dB: громче нашей нормы −14 LUFS и пик ≤ −1,5 dBTP).

## 1. «Tech in 5»: ударные волны и камень в почке (16 с)
Одна неподвижная плоская анатомическая таблица на весь ролик; меняется только состояние:
- **Одна величина в трёх видах сразу:** счётчик «780 импульсов ÷ 2 в с = 390 с» (число выведено арифметикой на экране), камень в круглой врезке ×4 крошится по шагам, ступенчатый график «самый крупный осколок, мм» с точкой, бегущей по тем же импульсам.
- **Врезка-лупа** с пунктирной линией к камню и подписью «×4, замедлено».
- **Честная строка** над таблицей: «условно: 2 имп/с, всего 3000; один показ = 250; замедлено, не в масштабе».
- Итоговая строка внизу с одним словом цветом.
- Слабо: подписи ~10 px, на телефоне не читаются; заголовок-вопрос висит весь ролик.

## 2. Цена ракеты против дрона (62 с): самый сильный по рассказу
- **Карточка цены:** название мелко, число крупно коралловым, источник и год мелко («Pentagon officials, 2023»). Признание незнания тоже карточка: «цена не публикуется».
- **Счёт предметами, где количество равно числу:** «одна ракета покупает сорок таких» — решётка из 40 дронов; «620 против 710» — две решётки точек в пропорции.
- **Чередование тёмного и светлого:** тёмные сцены для действия (море, дым, взрыв), светлая бумага для данных, карты и сравнений; жёсткие склейки между актами.
- **Жизнь слоя:** дождь, рябь моря, дым, всё тихо и постоянно движется.
- Карта с пунктирными траекториями, стрелки-маршруты; оговорки в тексте: «по заявлению России», «возможно, пятьдесят тысяч».
- Субтитры крупные, засечковые, внизу; ключевое слово цветом, без «таблетки».
- Финал возвращается к началу: «и счёт начинается снова».

## 3. Как работает пульсоксиметр (57 с): самый объясняющий
- **Цепочка наездов с прыжком масштаба:** прибор → палец → разрез пальца (кожа, жировые клетки, кость, артерия и вена) → лучи света → молекулы гемоглобина → сигнал → плата → итоговая схема «СВЕТ → СИГНАЛ → SpO₂» → возврат к прибору.
- **Заголовок сцены — утверждение:** «ПУЛЬС АРТЕРИИ МЕНЯЕТ СИГНАЛ», «ЭТО ОЦЕНКА, А НЕ ПРЯМОЕ ИЗМЕРЕНИЕ».
- **Бирки честности на экране:** «НЕ В МАСШТАБЕ», «ПУЛЬС ПРЕУВЕЛИЧЕН», «УПРОЩЕНО».
- **Число выводится по шагам:** сырой сигнал → пульс выделен (около 2 %) → красный и инфракрасный → «отношение отношений» → калибровочная кривая → результат.
- **Детальность узором:** соты жировых клеток, трабекулы кости, зерно ткани: приём «четыре раза» держится на текстурах заливки, а не на числе деталей.
- Подписи в чёрной плашке со светлым текстом (родня нашей «таблетки»).
- Слабо: пиксельный шрифт, много крошечного текста, сплошной тёмно-синий мир.

## Что берём в наш стиль (по приоритету)
1. **Бирки честности на экране** (`НЕ В МАСШТАБЕ`, `УПРОЩЕНО`, `ПРЕУВЕЛИЧЕНО`) как стандартный компонент рядом с моментом правды.
2. **Одна величина в трёх видах** (счётчик + объект + график с бегущей точкой от одних часов) как готовая плашка `TriSync`.
3. **Врезка-лупа** ×N с пунктирной линией и подписью «замедлено».
4. **Сетка единиц:** N одинаковых предметов, счёт равен числу, выделенная часть (`UnitGrid`).
5. **Число выводится на экране по шагам** (арифметика, отношение, кривая) как шаблон шага формата «В цифрах».
6. **Цепочка масштабов** прибор → разрез → клетка → молекула с шкалой «НЕ В МАСШТАБЕ» (есть `scale.tsx`; добавить шкалу и бирку).
7. **Узоры заливки** для детальности (соты клеток, трабекулы, волокна, зерно) в `materials.ts`.
8. **Карточка «цена не публикуется»:** незнание как карточка с источником.
9. **Решение за вами:** тёмный/светлый по актам (ролик 2) вместо «одна тёмная сцена»; засечковый шрифт для подписей.

## Чего не берём
Мелкий текст (< 26 px), заголовок-вопрос на весь ролик, пиксельный шрифт, один цвет мира на весь ролик, пики звука у 0 dB.
