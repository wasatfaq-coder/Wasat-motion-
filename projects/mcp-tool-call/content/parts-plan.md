# Копир для сцены MCP

Концепт универсального офисного копира. Конструкция на этом этапе условная. Счёт ниже задаёт объём будущей сборки Assembly. Проверку фактического числа деталей выполняем после моделирования.

| Группа | Детали | Количество |
| --- | --- | ---: |
| Основание | Цоколь, шасси, четыре опоры, четыре накладки, две боковины | 12 |
| Корпус | Верхняя панель, задняя стенка, две боковые панели, фасад, две сервисные дверцы, четыре петли, четыре вставки, две ручки, три решётки, два крепления | 22 |
| Сканер | Рамка стекла, стекло, крышка, подложка, две петли, два ограничителя, два упора, две планки | 12 |
| Подача бумаги | Два кассетных лотка, два фасада, две ручки, четыре направляющие, четыре ролика, четыре оси | 18 |
| Выдача результата | Ниша, лоток, две боковые направляющие, два ролика, две оси, два упора, выходной лист, вставка с содержимым листа | 12 |
| Управление | Опора панели, корпус, рамка, экран, кнопка запуска, четыре клавиши, два индикатора, крепление | 12 |
| Сервисный разрез | Две щеки, две направляющие, четыре ролика, четыре оси | 12 |
| **Всего** | | **100** |

Общий план показывает крышку сканера, панель управления, кассеты и выходную нишу. На крупном плане входной лист лежит на стекле, затем лист с видимым содержимым выходит между направляющими. Короткий разрез показывает ролики выдачи. Ролики опираются на оси, оси закреплены в боковых щеках, лист лежит на лотке. Подачу изображения и печать обозначаем как условный процесс.

В 360×640 зритель должен увидеть крышку, лоток и изменение состояния листа. Микродетали корпуса поддерживают крупный план. Коралловый акцент переходит с входного листа на выходной. Проверки после сборки: число деталей и опоры через object-audit, траектория листа и перекрытия по кадрам, узнаваемость объекта по эскизу.

[Детализированный концепт](copier-concept-detailed.png) показывает корпус и условный разрез узла выдачи. Проверено уменьшение до 360×640. На этом масштабе читаются подписи, ролики и лист.
