# Anatomy — шпаргалка

Пересказ без новых правил. Правила — `MASTER_PROMPT_FINAL.md` v3.0 (по разделам: `docs/rules/INDEX.md`); при расхождении действует регламент.

**Идея:** любая мысль показана как предметный мир, который работает на глазах у зрителя. Вскрытие — для реальных устройств.

## Кадр за 10 секунд
- Белые тела с серыми тонами граней в изометрии (вид исходного набора Anatomy), почти белый фон, тонкий тёмный контур, без узоров, один акцент — коралл с одним смыслом на ролик.
- Герой 45–55 % рабочей области, глубина тоном, детали у героя, тест прищура на 270 px.
- Настоящая локация в каждой сцене, у главы — своё место из общих кирпичей.
- Подписи сверху, ключевое слово в тёмной «таблетке», слова проявляются из размытия.
- «Табл. 01 / 04», выноски атласа (линия, номер, имя), плашки с источником и датой.
- Тонкий свет: тени в стыках, виньетка, градиент к герою, бумажная фактура 2–3 %. Поле главы светлое или тёмное по смыслу (тёмное — действие и ответ, светлое — данные и карты); смена только между главами.

## Режимы
| Режим | Когда | Пример |
| --- | --- | --- |
| Буквально | видимое: устройства, места, люди, интерфейсы, данные | чайник в разрезе, караван на карте |
| Схема | структура, шаги, шкала | плашка со счётчиком |
| Механизм | невидимое: чувства, решения, общество, понятия | «весы привычки» |
| Символ | состояние человека | туча гнева над манекеном |

Механизм: деталь = утверждение с источником; законы постоянны; не внутри головы; «упрощённо» и момент правды на плашке; один на главу; карточка из 5 пунктов на СТОП 1.

## Движение
Три слоя: событие на слове · отклик деталей с запаздыванием · тихая жизнь мира. Быстрый старт, мягкая посадка «в паз», каскад 2–4 кадра. Камера дышит (наезд 2–3 %) и даёт параллакс. Шесть переходов внутри главы, жёсткая склейка между главами. Событие каждые 1,5–2,5 с, микроинтрига каждые 5–8 с.

## Звук
Без музыки. Рассказчик «спокойный инженер». Звук по слоям, две настоящие тишины, звуковая подпись в одном месте каждого ролика.
