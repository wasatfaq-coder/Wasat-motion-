# MCP · вызов инструмента

Черновой фрагмент на 9 секунд. Источник — [архитектура MCP, Tool Execution](https://modelcontextprotocol.io/docs/learn/architecture#understanding-the-tool-execution-request).

| Время | План | Действие |
| --- | --- | --- |
| 0–3,3 с | Общий изометрический план | Заявка выходит из окна приёма и по направляющей поступает к рабочей станции. |
| 3,3–4,5 с | Крупный план | Станция принимает заявку. Камера приближает рабочий узел. |
| 4,5–9 с | Схема | Внутри контура хоста показан MCP-клиент. Он отправляет вызов серверу, который возвращает результат. На финальном кадре остаются обе стрелки. |

Заявка означает вызов инструмента. Направляющая означает связь клиента с сервером по MCP. Рабочая станция означает MCP-сервер. В кадре показан один вызов в рамках существующего подключения.

Ожидаемый пересказ — приложение через MCP-клиент отправляет вызов серверу, сервер возвращает результат. Ошибочное прочтение — модель напрямую подключается к базе или клиент находится внутри сервера. Подписи и контур хоста показывают реальные роли.

Статус — черновик для визуального и зрительского просмотра. Этот фрагмент объясняет принцип. Для отдельного теста реального интерфейса понадобится конкретное приложение и действие.

## Рендер

```bash
npx remotion render src/index.ts McpAnatomyPilot out/mcp-pilot.mp4 --codec=h264
node scripts/review-video.mjs out/mcp-pilot.mp4 out/mcp-review
```

Если загрузка браузера недоступна, укажи путь к установленному Chrome Headless Shell. Если Remotion также выдаёт ошибку `uv_interface_addresses`, включи локальный обход перечисления сетевых интерфейсов:

```bash
WASAT_REMOTION_BROWSER=/path/to/chrome-headless-shell \
NODE_OPTIONS="--require=./scripts/remotion-loopback.cjs" \
npx remotion render src/index.ts McpAnatomyPilot out/mcp-pilot.mp4 --codec=h264
```
