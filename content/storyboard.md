# Раскадровка (версия с локациями, 2026-11-12)

Стиль: изометрический Line Art, светлый фон, коралловый акцент. Текст в кадре — только заголовок превью (кадр 0 – ~1,3 с) и субтитры. Сквозной образ: листок календаря → карточка памяти → картотека с головой. Смена плана — каждые 1,5–3 с на ударных словах (шот-листы в коде сцен).

| Сцена | Локация | Что происходит (планы) |
| --- | --- | --- |
| 01 хук | Обложка А → комната | Часы и разлетающиеся листки + «Почему годы летят?» → часы обложки влетают в часы комнаты → листки срываются всё быстрее в картотеку → наезд в картотеку на «Почему?» |
| 02 ставка | Комната | Картотека → крупно часы (стрелка мчится) → картотека подсвечена на «ответ» → пунктирные «возможные» карточки |
| 03 опрос | Городская площадь → инфостенд | Опросчик с анкетой у скамейки → толпа человечков разного возраста на линии 14→94, счётчик 499 → край «14» → край «94» → наезд в инфостенд: ровные линии «час/неделя/месяц» |
| 04 десятилетие | Инфостенд (крупно) | Маркер рисует коралловую линию (камера следует за маркером) → кнопка и стикер «≈50 лет» → скобка «эффект небольшой» |
| 05 вывод | Комната | Часы подсвечены «не сами дни» → стопка в картотеке сжимается «годы» → общий план, пунктирная стрелка «назад» от часов к картотеке |
| 06 два способа | Остановка / комната | Остановка с часами, человек ждёт, проезжает машина → кадр делится диагональю: сверху «пока идёт» (остановка), снизу «назад» (картотека) |
| 07 отпуск | Пляж → комната | Пляж: солнце трижды пролетает по небу — дни летят → дома: чемодан открывается, яркие карточки летят в картотеку, стопка высокая — «Как так?» (повторный хук) |
| 08 новизна | Голова-шкаф | Чемодан → три крупные карточки (улица, билет, волна) → голова с ящичками памяти → карточки разлетаются по ящикам → рулетка вытягивается: период кажется длинным |
| 09 рутина | Квартал → комната | Кольцевая дорога: дом → офис → дом, машинка по кругу, серые одинаковые дни-следы → пауза → стопка в картотеке сплющивается (главная трансформация) |
| 10 версии | Торт и плёнки | Стикер «2» → торт жизни, кусок-год выезжает → торт растёт до 50 свечей, кусок тоньше → стикер «3» → плёнки: у молодого кадров больше |
| 11 оговорка | Блокнот | Маркер пишет знак вопроса → пузыри спорят → лупа: внимание, эмоции → вопрос зрителю |
| 12 совет | Квартал → комната | Кольцо размыкается в новые дороги (музей, парк, горы), яркие карточки летят домой → картотека растёт пунктиром → композиция обложки: «А час останется часом» |
